# Fonts

All four families are licensed under the SIL Open Font License 1.1 and were downloaded from Google Fonts (Arabic and Latin subsets only) on 21 Nov 2026. They are bundled so the Passport renders correctly with the network off (C3 requirement). Designer credits: see each family's page on fonts.google.com.

| Family | Role in Meyar |
|---|---|
| Readex Pro (variable 160–700) | Patient voice, Arabic and Latin |
| IBM Plex Sans Arabic (400–700) | Clinician voice, dashboards, tables |
| Alexandria (variable 100–900) | Headlines, wordmark, cover, big numbers |
| IBM Plex Mono (400–600, Latin) | Genotype data only |
