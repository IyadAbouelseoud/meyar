## Decisions made / open questions
- Crypto stayed in C2's `src/qr.js` (already WebCrypto, right parameters) instead of a new `src/crypto/` module — less churn, one source of truth.
- Emergency line = optional plaintext `e`, ≤120 chars, bound as AES-GCM AAD so an edited line fails decryption.
- Rate limit: 3 free tries, then 30 s / 60 s / 120 s / 300 s waits — UI parameters, not sourced claims; the UI shows only a live countdown. In memory only.
- 375 px patient issue screen could not be captured headless at true width (iframe harness rendered blank for index.html; scan.html worked). Recheck by hand at 375 px in a browser.
- Open for C4: all new Arabic strings are drafts for native-speaker review.

## Do not
- Do not reintroduce a default PIN or the patient ID in the payload.
- Do not rewrite passport files with PowerShell `Get-Content`/`Set-Content` without `-Encoding utf8` (it mangled Arabic once).
