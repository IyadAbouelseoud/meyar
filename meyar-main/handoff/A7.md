## Decisions made / open questions
- `docs/data-contract.schema.json` already specifies `currentMedications`, `effectivePhenotype`, and `phenoconversion` (`inhibitorStrength` enum: `["strong", "moderate", null]`). Weak inhibitors are recorded in `tables/cyp_inhibitors.json` from FDA but do not trigger phenoconversion (`applied: false`).
- `tables/mock_current_meds.json` uses per-patient rows (`patientId`, `medications[]`, `source`, `mock: true`) so patients with zero medications (`demo-001`) are represented explicitly.
- Activity score thresholds follow CPIC/DPWG consensus (Caudle et al. 2020) and Thomas et al. 2020: `0.0` → Poor, `0 < AS < 1.25` → Intermediate, `1.25 <= AS <= 2.25` → Normal, `> 2.25` → Ultrarapid.

## Do not
- Never overwrite `phenotype` (the genetic phenotype).
- Never compute a phenoconversion score for non-CYP2D6 genes.
- Never include any drug in `tables/cyp_inhibitors.json` whose inhibitor class is not on the FDA table.
- Never edit files outside the A7 scope lock.
