## English

### What Meyar is

People differ in how their bodies handle medicines. Some gene variants make a common drug (for example clopidogrel or codeine) work poorly, or cause harm, at the standard dose. This field is called pharmacogenomics. The guidelines exist, but the result of a genetic test rarely reaches the doctor at the moment of prescribing.

Meyar closes that gap in two parts:

1. **For the doctor.** When a doctor signs a prescription, Meyar checks it against the patient's stored genetic result and shows a short, non-blocking card: what the result means and what the published guideline (CPIC) recommends. The text comes straight from the guideline table. It is looked up, never generated by AI.
2. **For the patient: the Medication Passport (جواز الدواء).** An Arabic-first web app that holds the patient's result and works offline. The patient can show it as a PIN-protected QR code or a printed card, check an over-the-counter medicine, and switch to a large-text elder mode.

Built-in safety rules: germline (inherited) results only; genes whose result needs copy-number analysis (such as CYP2D6) are never guessed from a standard file and are shown as "not assessed"; the app never says a medicine is "safe"; both the genetic result and the result after the patient's current medicines are shown; every demo number has a source in [docs/sources.md](docs/sources.md).

There is also working software for a saliva-kit chain of custody (`kit/`) and a labelled roadmap of hardware concepts (`hardware/`, `docs/roadmap-cathlab.md`). Concept renders are marked "not built".

### How it works

```
Genotype source (lab / saliva kit)
  → germline-only gate → structural-variant gate
  → PharmCAT 3.4.0 (star-allele calling, once, in batch)
  → phenotype store (FHIR, HAPI) + data contract (JSON)
  → coverage and interpretability flag (Saudi allele frequencies)
  ├→ CDS Hooks service (cds/)      : card at prescription time
  └→ Medication Passport (passport/): offline patient app + QR
```

### Quick start

Needs Node.js 22 or newer. Docker is optional.

**Fastest: just the Passport (no Docker, no backend)**

```bash
cd passport
npm install
npm run dev          # open http://localhost:5173
```

Or skip all of this and open the live link above.

**Doctor-side service (no Docker)**

```bash
cd cds
npm start            # CDS Hooks service on http://localhost:3000
curl http://localhost:3000/cds-services   # discovery
# Alert dashboard: http://localhost:3000/dashboard
```

It needs no installation (Node standard library only) and falls back to the demo patients in `docs/fixtures/` when no FHIR server is running.

**With Docker (one command): FHIR server + doctor-side service**

```bash
docker compose up -d     # HAPI FHIR on 8080, CDS service on 3000
```

Then start the Passport as above. Saliva-kit software: `cd kit && npm start` (port 5174).

### Tests

```bash
cd cds && npm test        # CDS service
cd passport && npm test   # Passport, QR envelope, honesty lines
```

Details per folder are in each folder's own README. The full engine chain (`bash engine/run_pipeline.sh`) additionally needs Docker and Python 3.12.

## العربية

### ما هو معيار

يختلف جسم كل إنسان في طريقة التعامل مع الأدوية. بعض الاختلافات الجينية تجعل دواءً شائعًا (مثل كلوبيدوغريل أو الكودايين) ضعيف الفعالية أو ضارًا بالجرعة المعتادة. يسمى هذا المجال علم الجينوم الدوائي. الإرشادات العلمية موجودة، لكن نتيجة الفحص الجيني نادرًا ما تصل إلى الطبيب لحظة كتابة الوصفة.

يسد معيار هذه الفجوة بجزأين:

1. **للطبيب.** عند توقيع الوصفة يقارنها معيار بالنتيجة الجينية المحفوظة للمريض ويعرض بطاقة قصيرة لا تعطّل العمل: ما معنى النتيجة وماذا توصي الإرشادات المنشورة (CPIC). النص مأخوذ من جدول الإرشادات مباشرة، يُبحث عنه ولا يولّده الذكاء الاصطناعي.
2. **للمريض: جواز الدواء.** تطبيق ويب بالعربية أولًا يحفظ نتيجة المريض ويعمل بلا إنترنت. يعرضه المريض برمز QR محمي برقم سري أو ببطاقة مطبوعة، ويمكنه فحص دواء بدون وصفة، وتفعيل وضع كبار السن بخط كبير.

قواعد الأمان المضمّنة: النتائج الوراثية الموروثة فقط؛ الجينات التي تحتاج تحليل عدد النسخ (مثل CYP2D6) لا تُخمَّن من ملف عادي وتظهر «لم تُقيَّم»؛ لا يقول التطبيق إن دواءً «آمن»؛ تُعرض النتيجة الجينية والنتيجة الفعلية بعد أدوية المريض الحالية معًا؛ وكل رقم في العرض له مصدر في [docs/sources.md](docs/sources.md).

ويتضمن المشروع برنامجًا يعمل لسلسلة حفظ عينة اللعاب (`kit/`) وخارطة طريق للأجهزة بنماذج تصورية موسومة «لم يُبنَ» (`hardware/`).

### تشغيل سريع

يتطلب Node.js الإصدار 22 أو أحدث. Docker اختياري.

**الأسرع: الجواز فقط (بدون Docker)**

```bash
cd passport
npm install
npm run dev          # افتح http://localhost:5173
```

أو افتح الرابط المباشر أعلاه دون تثبيت أي شيء.

**خدمة جهة الطبيب (بدون Docker)**

```bash
cd cds
npm start            # الخدمة على http://localhost:3000
curl http://localhost:3000/cds-services
# لوحة التنبيهات: http://localhost:3000/dashboard
```

**بأمر واحد عبر Docker: خادم FHIR + خدمة الطبيب**

```bash
docker compose up -d     # HAPI FHIR على 8080 وخدمة CDS على 3000
```

ثم شغّل الجواز كما سبق. برنامج عُدّة اللعاب: `cd kit && npm start` (المنفذ 5174).
