# مِعيار · Meyar

**The right dose, the first time.** الجرعة الصحيحة من أول مرة

Pharmacogenomics prescribing safety for Saudi patients. KKU Health Innovation Hackathon, track: Predictive Healthcare.

> Research prototype — not for clinical use. Runs on synthetic and GeT-RM reference data; no patient data was used.

**Start here, every agent and teammate: [AGENTS.md](AGENTS.md)** — every settled rule. Then your task prompt in [prompts/](prompts/README.md), your [handoff file](handoff/README.md), and the background digest in [docs/research/](docs/research/README.md).

## Architecture

```
Genotype source (hospital lab, regional array, chain-of-custody saliva kit [F3])
        │
        ▼
Germline-only gate [A6] ── rejects tumour (somatic) samples
        │
        ▼
Structural-variant gate [A8] ── CYP2D6 is never called from a VCF; it comes
        │                          from an outside call, or is "not assessed"
        │
        ▼
PharmCAT 3.4.0 in Docker, batch, ONCE — no Saudi logic inside here [A2]
        │
        ▼
Phenotype store: FHIR Observation, Genomics Reporting IG (HAPI) [A4]
        │
        ▼
A5 COVERAGE & INTERPRETABILITY FLAG [A5]
  inputs:  assayed defining positions × Saudi allele frequency table
  outputs: positions assayed / total, untested locally common alleles,
           uninformative-Normal-Metaboliser risk score
        │
   ┌────┴──────────────────────────────┐
   ▼                                   ▼
CDS Hooks order-sign [B2–B6]      Medication Passport [C1–C9]
non-interruptive card             Arabic-first, elder mode, OTC quick-check,
+ phenotype + guideline version   PIN-encrypted offline QR (payload, not URL),
+ the A5 flag                     printable ID-1 card
+ backward sweep of current meds
```

A5 is a separate arithmetic step after interpretation. It never re-picks a diplotype; all PharmCAT candidates are shown.

## Run

```
docker compose up -d                       # HAPI on 8080, CDS on 3000
curl localhost:3000/cds-services            # discovery
# Whole engine chain from a clean clone: A1 VCFs -> PharmCAT 3.4.0 in Docker (A8 outside calls) -> A3 -> A4/A6 -> A5 -> A8 -> A7.
# The VCFs are generated, not committed. Needs Python 3.12 with jsonschema, e.g.:
PYTHON="uv run --no-project --python 3.12 --with jsonschema python" bash engine/run_pipeline.sh
npm --prefix passport ci && npm --prefix passport run dev   # Passport on 5173
npm --prefix kit start                                      # kit on 5174
npm --prefix tests/mobile ci && npm --prefix tests/mobile test   # mobile regression (every page, 320-430 px)
```

Deploy the Passport (static, offline-capable): `npm --prefix passport run build`, then publish the whole `passport/dist/` folder (Netlify publish directory `passport/dist`; `_headers` sets caching). The build regenerates `sw.js` with the full precache list, so always upload `dist` as one set.

PharmCAT needs GRCh38 with `chr` prefixes. Never use the flags its docs label DANGEROUS.

## House rules

- No unsourced number anywhere. Every number has a row in [docs/sources.md](docs/sources.md).
- Dosing is looked up from `tables/cpic_recommendations.json`, copied verbatim from the CPIC database (DPWG not included; model cross-check only, not yet clinician-reviewed: see docs/cpic-signoff.md). Never generated by a model.
- Germline only. Tumour profiling is separate and never interpreted here.
- Genes whose result depends on copy number or hybrid genes are never called from a VCF. See [docs/structural-variants.md](docs/structural-variants.md).
- Saudi frequencies are tiered: no published Saudi figure means no score, never a borrowed one.
- Every hardware image carries its status label. Nothing not built is shown as built.
- The demo and presentation run on **mock data** only, so an unverified regulation never blocks a build task. Mock rows carry `"mock": true`.
- Both the genetic phenotype and the effective phenotype (after the patient's current medicines) are always shown; neither replaces the other.
- Alternatives are shown only where a CPIC row names one. Never generated, never ranked.
- Every screen is built from [design/](design/README.md): the Meyar Scale for every phenotype, status as shape + word + colour, never "safe". See the live [showcase](design/showcase/index.html).
- Every task keeps `handoff/<TASK>.md` current and stops safely when limits approach (AGENTS.md section 3).
